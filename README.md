# Радар роста: свой бот вместо ленты соцсетей

![Радар роста](assets/cover.jpg)

Личный Telegram-бот, которого Claude Code собирает под тебя. Сначала он спрашивает, кто ты, куда хочешь расти, какие фильмы и книги тебе заходят. Потом каждое утро присылает подборку только под твои цели:

- **фокус дня** — одна тема из твоей карты роста и где она встречается в твоей работе;
- **2–5 новостей**, которые важны именно тебе, без бесконечной ленты;
- **3 материала на выбор**: видео, подкасты, аудиокниги — сразу прямой ссылкой (хочешь практиковать английский — будут и на нём);
- **вопрос дня**.

Под каждым пунктом кнопки «Беру / Изучил / Не моё». Можно ответить текстом или голосом: «мимо», «зашло», «объясни попроще». Бот запоминает и назавтра попадает точнее. По воскресеньям присылает итог недели: что изучил и куда сдвинулся.

Без кода, ставится минут за 15.

## Что понадобится

- Подписка Claude Pro ($20 в месяц) или выше: Claude Code входит во все платные планы, на бесплатном его нет. Бот работает на этой же подписке, отдельно платить за API не нужно. Подборка тратит около 15 тыс. токенов в день — малая часть лимита.
- Mac (бот живёт на нём и запускается сам по расписанию).
- Telegram.

## Как поставить

1. Поставь Claude Code: открой Терминал (Cmd+Пробел → «Терминал»), вставь команду и нажми Enter:

   `curl -fsSL https://claude.ai/install.sh | bash`

   Затем открой новое окно Терминала, напиши `claude` и войди в свой аккаунт Claude.
2. В Claude Code напиши:

   `Собери мне радар роста из https://github.com/ndsmirnov/claude-growth-radar`

3. Он задаст несколько вопросов о тебе: работа, цели, как удобно учиться, что уже лежит «на потом». Отвечай как есть, можно голосом (диктовка Mac: дважды Fn).
4. Он попросит создать бота: в Telegram открой @BotFather → `/newbot` → любое имя → пришли ему токен.
5. Напиши своему боту `/start`, потом `/today` — придёт первая подборка.

## Что внутри

| Что | Зачем |
|---|---|
| `skills/growth-radar/SKILL.md` | Пошаговый процесс для Claude: проверка, интервью, настройка, установка |
| `skills/growth-radar/template/` | Готовый код бота: утренняя подборка, бот с кнопками, недельный итог, установка |
| `skills/growth-radar/hooks/radar-backlog.py` | Напоминание Claude о твоих просьбах доработать бота (по желанию) |

## Как пользоваться

- **Отвечай на подборку.** Кнопки или реплай текстом/голосом. Чем больше ответов, тем точнее завтра.
- **Команды:** `/today` — подборка сейчас, `/vector` — карта роста, `/plan` — фазы, `/pause` и `/resume`.
- **Хочешь поменять сам бот** («присылай позже», «меньше новостей») — напиши ему. Он запишет просьбу, а Claude Code сделает её в обычной сессии по фразе «сделай доработки радара».

# Инструкция для Claude (выполни по порядку)

Ты ставишь пользователю радар роста. Он может быть не разработчиком: объясняй коротко и по-русски, после каждого шага одной строкой пиши, что сделано. Ничего не устанавливай без объяснения одной строкой, что это и зачем.

1. `PKG` = папка, где лежит этот README. Если пользователь дал ссылку на GitHub — скачай архив: `curl -sL https://github.com/ndsmirnov/claude-growth-radar/archive/refs/heads/main.tar.gz | tar -xz -C /tmp`, тогда `PKG` = `/tmp/claude-growth-radar-main` (git не нужен; именно tar.gz — `unzip` на Mac ломает русские имена файлов).
2. Скопируй скилл: `mkdir -p ~/.claude/skills && cp -R "$PKG/skills/growth-radar" ~/.claude/skills/`.
3. Прочитай `~/.claude/skills/growth-radar/SKILL.md` и выполни его по шагам 0–5. В начале интервью спроси, как обращаться (имя и род), и дальше пиши в нужном роде.
4. Пароль от Мака нужен только для автопробуждения по утрам — сначала спроси, нужно ли оно.
