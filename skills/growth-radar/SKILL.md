# Радар роста — сборка личного бота

Бот живёт на Маке владельца: Python без лишних зависимостей + `claude -p` на его подписке Claude (без API-ключа) + Telegram-бот. Код уже готов в `template/`. Твоя работа — понять человека и настроить бота под него. Писать с нуля ничего не нужно.

Как устроено:
- `digest.py` — утром собирает свежие посты из RSS-лент, отдаёт их Claude вместе с профилем, картой роста и обратной связью. Шлёт в Telegram: фокус дня, где это видно в работе, вопрос дня, 2–5 новостей, 3 материала на выбор с прямыми ссылками на YouTube и закреплённую сводку дня.
- `bot.py` — работает постоянно. Принимает кнопки (🔥/👍/👎, ▶️ Беру, ✅ Изучил), ответы текстом и голосом. Куратор отвечает и раскладывает реплику на три части: вкус (`preferences.md`), рост по теме (`data/progress.json`) и просьбы доработать бота (`backlog.md`).
- `weekly.py` — по воскресеньям сжимает обратную связь, обновляет уровни, пишет итог в `vector.md` и в Telegram.
- `install.py` — ставит три задания launchd: бот, подборку и недельный итог.

Расход: подборка — около 15 тыс. токенов Sonnet в день, ответ на реплику — 3–5 тыс. Это малая часть лимита подписки.

## Шаг 0 — проверить, что всё живо (до интервью)

1. `sw_vers` — это macOS. На Linux вместо launchd нужен systemd/cron, предупреди владельца и адаптируй `install.py`.
2. `python3 --version` — нужен 3.9 или новее. Запомни путь: `which python3`.
3. `claude --version`, потом пробный вызов: `cd /tmp && claude -p "ответь: ок" --model sonnet --output-format json --tools "" --setting-sources "" --no-session-persistence`. Если ругается на флаг — `claude update` и повторить. Если просит логин — `claude` → `/login`.
4. `curl -sm 10 -o /dev/null -w "%{http_code}" https://api.telegram.org` — Telegram доступен (иначе нужен VPN).

Упало одно и то же два раза подряд — не долбить, сказать владельцу.

## Шаг 1 — интервью (коротко, блоками, не анкетой)

Спроси по-человечески, 2–3 сообщения максимум:
1. Кто ты сейчас: работа, роль, чем занят(а) каждый день, какие слова и инструменты видишь постоянно, но не до конца понимаешь.
2. Куда хочешь через год и через 3 года. Что хочешь прокачать. Где хочешь работать или что делать.
3. Как удобно учиться: смотреть, слушать или читать; когда (дорога, обед, вечер); сколько минут. Язык: русский; иностранный — для чего.
4. Что точно не заходит. Есть ли принципы (например, «не сидеть в лентах»).
5. Во сколько присылать подборку. Нужны ли голосовые.
6. Есть ли «отложка» — сохранённые книги, фильмы, курсы, к которым хочешь вернуться. Если да — пусть пришлёт списком или выгрузкой, сделаешь из неё `library.md`.

Не додумывай за человека. Чего не сказал(а) — оставь пустым или спроси.

## Шаг 2 — развернуть бота

1. Папка: `~/growth-radar` (в домашней папке, НЕ на Рабочем столе и не в Документах — иначе macOS не пустит фоновые задания без «Полного доступа к диску»).
2. `cp -R <этот скилл>/template/. ~/growth-radar/` и `mkdir -p ~/growth-radar/data/sent`.
3. По интервью написать:
   - `profile.md` — по образцу `profile.example.md`, конкретно и коротко, словами человека;
   - `roadmap.json` — по образцу `roadmap.example.json`: поле `title`, 3–4 трека, в каждом 4–8 тем, стартовый уровень `start` 0–4 по его словам, 3–4 фазы погружения (`from_week`, цель, темы фокуса). Удали `profile.example.md` и `roadmap.example.json` после того, как написал свои;
   - `vector.md` — заполнить раздел «Видение» (фазы таблицей). Маркеры `radar:progress` и `radar:log` не трогать;
   - `library.md` — если есть отложка: по темам, с пометкой, к какой теме роста относится.
4. `feeds.json` — подобрать 10–20 RSS-лент под его темы (там пример про продукт и AI — заменить). Проверить: `python3 -I digest.py --feeds`. Мёртвые убрать. Telegram-каналы напрямую не читаются — только RSS (у многих сайтов есть `/feed`, `/rss`; для Хабра — `habr.com/ru/rss/hubs/<хаб>/articles/`).

## Шаг 3 — Telegram

1. Владелец: @BotFather → `/newbot` → имя → присылает токен.
2. `cd ~/growth-radar && python3 -I -c "import common as c; c.set_env('TG_TOKEN','<токен>'); print(c.tg('getMe')['username'])"` — `.env` создаётся с правами 600.
3. Владелец пишет боту `/start` — первый, кто написал, становится владельцем (`TG_CHAT_ID` запишется сам, когда бот запущен). Чужим бот не отвечает.

## Шаг 4 — пробный прогон и установка

1. `python3 -I digest.py --dry` — подборка без отправки. Показать владельцу коротко: фокус, новости, материалы. Не нравится — поправить `profile.md` или `roadmap.json`, не код.
2. Время подборки: в `install.py` — `StartCalendarInterval` у `digest` (по умолчанию 7:45 и запасной запуск в 10:00; повторно в тот же день не шлёт). Недельный итог — воскресенье 19:00.
3. `python3 -I install.py install`, затем `python3 -I install.py status` — бот должен иметь PID.
4. Владелец пишет `/today` — приходит первая настоящая подборка. Затем отвечает на что-нибудь голосом или текстом и проверяет, что куратор ответил.
5. Голосовые (если нужны): `python3 -m pip install --user faster-whisper` тем же python. Первый раз модель скачается (~500 МБ).
6. Чтобы подборка приходила, когда Мак закрыт, нужно автопробуждение (спросить владельца): `osascript -e 'do shell script "/usr/bin/pmset repeat wakeorpoweron MTWRFSU 07:45:00" with administrator privileges'`. Пароль вводится в системном окне. Время — как у подборки. Подборка уже обёрнута в `caffeinate`, Мак не уснёт посреди сборки.
7. Хук доработок (по желанию): `hooks/radar-backlog.py` скопировать в `~/.claude/hooks/` и добавить в `~/.claude/settings.json` → `hooks.SessionStart` команду `python3 ~/.claude/hooks/radar-backlog.py 2>/dev/null || true`. Тогда при старте сессии Claude напомнит о просьбах из `backlog.md`.

## Шаг 5 — объяснить владельцу (простыми словами, 5–7 строк)

- Каждое утро подборка, сверху закреплена сводка дня.
- Кнопки под пунктами; ответ реплаем текстом или голосом — бот учится. «Объясни X» — объяснит.
- `/vector` — карта роста, `/plan` — фазы, `/today` — подборка сейчас, `/pause` и `/resume`.
- Просьбы поменять сам бот («присылай позже», «меньше кнопок») бот записывает в доработки. Их делает Claude Code в обычной сессии: «сделай доработки радара».

## Поддержка и правки

- Логи: `~/Library/Logs/growth-radar/` (`claude.log` — расход на каждый вызов, `bot.log`, `digest.log`).
- Доработки из `backlog.md`: сделать → `- [x]` с датой → `python3 -I install.py install`, если менялся `bot.py` (перезапуск бота).
- Код менять только по просьбе владельца. Вкус контента — это `preferences.md` и `profile.md`, не код.

## Грабли (уже обойдены в коде — не ломать)

- `claude -p` вызывается с `--setting-sources "" --tools "" --strict-mcp-config` из `/tmp`: не грузятся CLAUDE.md, хуки и MCP владельца. Иначе каждый вызов дороже и могут сработать чужие хуки.
- Ответ куратора с кривым HTML Telegram отклоняет (400) — бот повторяет простым текстом.
- Две подборки одновременно (кнопка `/today` во время утреннего запуска) — защищено lock-файлом.
- Ссылки на YouTube — прямые: бот берёт первый ролик из выдачи по точному запросу и показывает реальное название, канал и длительность. Ссылки в новостях — только из RSS, модель их не придумывает.
- После перезагрузки Мака с FileVault задания стартуют только после входа в систему.
